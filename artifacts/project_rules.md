# Math Action RPG - 開発共通ルール

## 1. テキストとUIにおける「漢字制限・フリガナ」の必須ルール
本ゲームは小学生（低学年〜中学年）をメインターゲットとしているため、以下のルールを**システム全体の前提**として必ず遵守すること。

*   **HTMLの静的テキスト**: 漢字を使用する場合は、必ず `<ruby>漢字<rt>かんじ</rt></ruby>` の形式でフリガナを振ること。
*   **JavaScriptからの動的テキスト生成**: タイピングアニメーション（1文字ずつの描画）など、HTMLタグが混ざると表示が崩れる懸念がある箇所では、**そもそも漢字を使用せず、すべて「ひらがな・カタカナ」で記述**すること。（例：「大変です！」→「たいへんです！」）
*   **音声読み上げ（SpeechSynthesis）**: 子供が自然に聞き取れるよう、ふりがなやひらがなベースの自然なテキストを読ませること。

## 2. デザインの品質
*   常にカラフルでポップ、かつ高品質な3D表現（PBRマテリアルやパーティクル）を維持すること。
*   汎用的な色や簡素な図形だけでなく、影や光（Emission）、アニメーション効果を用いてリッチな画面作りを心がけること。
